Cyber-Chase is set in a retrofuturistic world inspired by synthwave, vaporwave and 80s VHS aesthetics. It is a simple arcade-style game in which the player must outrun the police through neon-lit streets. It was created in 2018 as a personal learning challenge, built from a mix of tutorials and study materials.

## Quick start

There is no release or ready-made build yet, so the game currently runs from source in the Unity editor.

1. Clone this repository and open its root folder as a project in Unity. The editor version is listed in [`ProjectSettings/ProjectVersion.txt`](ProjectSettings/ProjectVersion.txt).
2. Open the scene [`Assets/Scenes/Menu.unity`](Assets/Scenes/Menu.unity) and press Play.

## About this archive

The purpose of this repository is to preserve the first functional game I ever made and keep it playable on modern versions of Unity. The original gameplay and visual identity remain intact, while selected legacy systems have been modernized and small quality-of-life and reliability improvements have been introduced.

- **Preserving history** — the project stays a milestone of my early development journey.
- **Working on modern Unity** — the game is kept functional on current editor versions.
- **Retro style** — the original synthwave atmosphere and visual style are maintained.
- **Careful modernization** — legacy systems are updated and gameplay improved without changing the character of the original project.
